Infinity Books

Infinity Books is a digital library application that allows users to browse books, search, and manage their favorite books.

How I built it

  1. Created the React frontend.
  2. Built an Express backend to manage books.
  3. Connected the frontend to the backend API.
  4. Added search, favorites, likes, and bookmarks.
  5. Implemented a PDF reader.

Technologies Used

  • HTML
  • CSS
  • JavaScript
  • React
  • Node.js and Express

Read Later

Read Later is a web application that allows users to save articles from the internet and read them later.

How I built it

  1. Created the React frontend.
  2. Built an Express backend to handle article requests.
  3. Connected the backend to a MySQL database using Prisma.
  4. Used Readability to extract article content from web pages.
  5. Added functionality to save and manage articles.

Technologies Used

  • HTML
  • Tailwind CSS
  • JavaScript
  • React
  • Node.js and Express
  • MySQL and Prisma
